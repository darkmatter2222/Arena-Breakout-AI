# Vision

Real-time single-class object detection pipeline built on **YOLO11n** (Ultralytics).  
Covers the full lifecycle: screen capture → annotation → training → live inference.

## Project Structure

```
vision/
├── capture.py             # High-perf screen capture (mss/DXGI, 600×416 center crop)
├── annotate.py            # Tkinter annotation GUI with AI-assisted predictions + bulk mode
├── train.py               # YOLO11n training with text-file splits, auto-resume, evaluation
├── detect.py              # Real-time detection agent (30 FPS, cursor movement, overlay)
├── eda.py                 # Exploratory data analysis on YOLO labels
├── scrub_overlaps.py      # Archive images with overlapping bboxes (IoU > 0)
├── strip_tiny_boxes.py    # Remove boxes smaller than 16 px at 640 imgsz
├── requirements.txt
├── models/
│   └── best.pt            # Production model weights (copied after training)
├── dataset/
│   ├── images/            # All labeled images (flat)
│   ├── labels/            # YOLO .txt labels (flat, one per image)
│   ├── splits/            # train.txt / val.txt generated by train.py
│   ├── archive/           # Excluded data (overlapping boxes, etc.)
│   └── data.yaml          # YOLO dataset config
├── captures/              # Raw screenshots from capture.py
├── harvest/               # Auto-saved detection frames from detect.py
├── runs/                  # Training run artifacts (logs, plots, weights)
│   └── yolo11n_target/    # Latest training run
└── logs/                  # Capture engine logs
```

## Pipeline

```
capture.py ──→ captures/ ──→ annotate.py ──→ dataset/{images,labels}/
                                                      │
                                     ┌────────────────┘
                                     ▼
                               train.py ──→ runs/yolo11n_target/ ──→ models/best.pt
                                                                          │
                                                          ┌───────────────┘
                                                          ▼
                                                     detect.py (live inference)
```

### 1. Capture — `capture.py`

Captures the center 600×416 region of the screen using DXGI desktop duplication via `mss`.  
Multi-threaded JPEG writer for high throughput. Output goes to `captures/`.

### 2. Annotate — `annotate.py`

Tkinter GUI for single-class bounding box annotation.

- **AI-assisted**: loads `models/best.pt` for prediction suggestions on unannotated images
- **Bulk mode**: 4×4 grid with confidence filtering for rapid annotation
- **Controls**: left-click drag to draw, right-click to delete, Space to skip (negative sample), Shift to accept AI prediction, Ctrl+Z to undo
- **Auto-advance**: optional checkbox to move to next image after drawing a box

Output: copies images to `dataset/images/` and writes YOLO-format `.txt` labels to `dataset/labels/`.

### 3. Preprocess (optional utilities)

| Script | Purpose |
|---|---|
| `eda.py` | Full statistics on label data — box sizes, distributions, overlaps, problems |
| `scrub_overlaps.py` | Archive images where any two boxes overlap (IoU > 0) to `dataset/archive/` |
| `strip_tiny_boxes.py` | Remove boxes with any side < 16 px at 640 imgsz from label files in-place |

### 4. Train — `train.py`

```bash
python train.py
```

- Generates `dataset/splits/train.txt` and `val.txt` (85/15 split, seed 42)
- Writes `dataset/data.yaml` pointing to the text-file splits
- Trains YOLO11n with auto-resume, early stopping (patience 30), checkpoints every 25 epochs
- Runs full evaluation after training with per-image predictions saved
- Copies `best.pt` → `models/best.pt`

**Key hyperparameters** (edit at top of `train.py`):

| Param | Default | Notes |
|---|---|---|
| `EPOCHS` | 150 | Max epochs before early-stop |
| `BATCH_SIZE` | 16 | Fits RTX 5090 comfortably |
| `IMGSZ` | 640 | Standard YOLO input size |
| `PATIENCE` | 30 | Early-stop epochs |
| `VAL_SPLIT` | 0.15 | 15% held out for validation |
| `SEED` | 42 | Reproducible splits |

### 5. Detect — `detect.py`

Real-time inference agent. Captures screen, runs YOLO detection, moves cursor to nearest target.

- Loads `models/best.pt`
- Numpad 5: toggle armed (cursor movement on RMB hold)
- Numpad 2: toggle detection tick sound
- Numpad 3: toggle auto-harvest (save detection frames)
- Numpad 6: toggle frame capture
